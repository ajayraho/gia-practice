Column Match

Perceptual speed practice, Thomas GIA format.

How many columns have the same letter?

A three-minute test. Each question shows a lowercase letter above an uppercase letter in each column. Case doesn't matter - "r" and "R" are the same letter. Count the matching columns and answer as fast as you can.

Sample question
rjep
RPLP
r/R match, p/P match → 2
How many columns have the same letter?

Furthest Out

Numbers speed and accuracy practice, Thomas GIA format.

Which number is furthest from the median?

A three-minute test. Each question shows three numbers. Find the middle one, then decide whether the highest or the lowest number sits further away from it. No calculator, just quick comparison.

Sample question
11144
Median is 11. |14−11|=3, |4−11|=7 → 4
Which number is furthest from the median?

True Turn

Spatial visualization practice, Thomas GIA format.

How many boxes have the same letter?

A three-minute test. Each box shows a letter twice - once plain, once turned. A letter that's just rotated still counts as the same letter. A letter that's been mirrored (flipped, like in a mirror) does not, even if it's spun around too.

Sample question
SS
SS
Box 1 is just rotated - same letter. Box 2 is mirrored - not the same. → 1
How many boxes have the same letter?
Rotated letters count as the same. Mirrored letters don't.
